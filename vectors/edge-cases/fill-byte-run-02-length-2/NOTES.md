# fill-byte-run-02-length-2

A run of 2 0xFF fill byte(s) immediately before a JUMBF APP11 segment, inserted after sealing. §4.1 keeps fill bytes and drops only the JUMBF segment, so canonical bytes equal the unmodified base image and `media.hash` still matches. Run length 2 exercises the marker-walk one byte at a time (`pos += 1` per fill byte) at a boundary generate.ts's single "APP11 present" vectors never sweep.

Generated by `tools/src/generate-edge-cases.ts` (seed 1) with the test key in `tools/src/testkey.ts`.
