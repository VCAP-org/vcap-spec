# trailer-truncated-08-cut-24

The sealed file with its last 24 bytes removed (footer is 16 bytes, box header 8). Every cut in this sweep leaves either a torn magic or a payload length the remaining bytes cannot satisfy, so §3's structural check fails before the CRC is ever read: *no proof found*, never *corrupted* — a platform stripping the tail and an attacker editing it must not read the same at this boundary, and this sweep is the boundary.

Generated by `tools/src/generate-edge-cases.ts` (seed 1) with the test key in `tools/src/testkey.ts`.
