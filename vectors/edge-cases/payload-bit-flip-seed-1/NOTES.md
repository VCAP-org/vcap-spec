# payload-bit-flip-seed-1

Seed 1 picked byte offset 429 of the payload and bit 0x1; flipping it changes the payload without touching the footer, so the CRC — computed over the unmutated payload — no longer matches: *corrupted proof*. The only case in this generator where "same seed, same bytes" is doing real work: every other case is an exhaustive sweep with nothing left to a seed.

Generated by `tools/src/generate-edge-cases.ts` (seed 1) with the test key in `tools/src/testkey.ts`.
